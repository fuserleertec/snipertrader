DATA PROVENANCE — WHAT IS REAL, WHAT IS A MODEL
REAL · computed from live OHLCV MODEL · deterministic ensemble options flow / dark pool / tape (key-gated, not present)

Prices, change, Kronos structure (VWAP · FVG · order blocks · sweeps · MSS), ATR, the empirical probability cone, trade levels, and the walk-forward backtest are all computed from real daily OHLCV (Yahoo, key-less, ~2 years). The MiroFish swarm is a deterministic 8-model ensemble — every vote is a real formula over the same data, not a random draw — but it is a model, not a live tape of traders. There is no order-flow / dark-pool / options data here and none is implied. Static snapshot — data as of ; regenerate with teardown/fetch_data.py → compute_engine.py → build_html.py.
