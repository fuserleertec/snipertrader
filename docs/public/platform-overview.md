# SniperTrader.ai Platform Overview

SniperTrader.ai is an AI-powered trading-education and tools business. It teaches
systematic trading methodology and provides AI-assisted tools for market analysis
and risk management. This page is a high-level tour of the product surface.

## Courses

- **USME/ICT Foundation** — foundational trading methodology.
- **VWAP Suite** and **VWAP Elite** — courses built around volume-weighted average price trading.
- **Prop Firm MasterPlan** — preparation for proprietary trading firm evaluations.
- **30-Day Funded Challenge** — a structured, time-boxed challenge program.
- **Workshops** — scheduled workshop content.
