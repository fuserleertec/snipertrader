Module 01 · Setup & Environment Calibration

Setup & Environment Calibration

Get the indicator on the chart. Align time. Then the engine can read sessions the way institutions do.

1.1 Pine Script v6 Indicator Installation

Meridian Engine v2 is a Pine Script v6 indicator. Pine Script is TradingView’s chart language. Version 6 is the current editor format. Load it once. Leave it on.

  1. Open the chart. TradingView → your instrument. Then open the Pine Editor at the bottom of the screen.
  2. Paste Meridian Engine v2. Drop the v6 script into the editor. Save. Click Add to Chart.
  3. Use standard candlesticks. Set candles to Bar-Close / Standard. Do not use Heikin-Ashi for this work.
Heikin-Ashi averages candles. That smears exact highs and lows. Liquidity levels need the real wick. Use standard candles.

After the script is on the chart you should see the Trend Cloud, the EMA ribbon, VWAP bands, and lattice labels as they print. If nothing appears, confirm the script compiled without errors and that you added it to this chart pane.

1.2 Session DNA & Timezone Alignment

Session DNA is Meridian’s name for the day’s institutional windows. The engine treats those windows as amplifiers — they raise a setup’s lattice grade when they line up.

Set the chart timezone to America/New_York (EST / EDT, UTC−5 / UTC−4). Every time in this course is New York time.

Asia Range — 20:00–00:00. Overnight box. London often sweeps it.
London Window — 02:00–05:00. First real expansion of the day.
Silver Bullet — 08:00–09:00. Tight one-hour hunt for a displacement.
NY AM Kill Zone — 08:30–11:00. Open drive and first New York expansion.

Set alerts to Any alert() function call or Once Per Bar Close. Mid-bar noise is not a signal. The close is.

Plain English: lock New York time. Know the four windows. Only take alerts after the candle finishes.
Module 02 · Deconstructing the Meridian Code Mechanics

Deconstructing Meridian Mechanics

Four analysis pillars feed a 3-Gate Core. Read them in order: regime, memory, lattice, then risk.

2.0 The 6-Pillar Core Engine

Older scripts used rigid AND-gates — every filter had to be true or nothing printed. Meridian v2 is a 6-pillar engine. Four pillars classify the tape. The last two are execution: the 3-Gate Core, then the managed path.

Analysis pillars

  • 01 Regime Engine — TREND, RANGE, or TRANSITION
  • 02 Memory Map — swept pools stored as magnets
  • 03 Lattice Confluence — how many events agree
  • 04 Risk Geometry — SL, entry, TP1 / TP2 / TP3

Execution pillars

  • 05 3-Gate Core — Bias → Armed → Zone Retest
  • 06 Path Integrity — PATH CONFIRM or PATH BREAK

This module goes deep on pillars 1 and 2. Pillars 3–6 get a first look here, then full playbooks in Modules 03–05.

2.1 Pillar 1 — The Regime Engine

A regime is the market’s current mood: it is trending, ranging, or changing. Meridian classifies that mood before it will arm a trade.

Three tools feed the call. ATR (Average True Range) measures typical candle size — is this move large for this market? ADX(14) (Average Directional Index, 14 bars) measures trend strength. Above 20 = a trend is present. The EMA ribbon is three exponential moving averages — 9, 21, and 50 — stacked as a cloud.

TREND

ADX above 20. ATR showing relative strength. EMA 9 / 21 / 50 stacked in one direction.

Action: trade with the Trend Cloud. Enforce No-Chase distance filters. Do not buy the spike.

RANGE

ADX below 20. Ribbon is flat. Price is oscillating around fair value.

Action: fade VWAP extremes at ±1σ and ±2σ. Mean reversion, not breakout chasing.

TRANSITION

Regime is shifting, or volatility is squeezed. The old mood is dying. The new one is not proven.

Action: wait. Demand a higher lattice grade before you arm.

No-Chase means: if price has already run far from the cloud or VWAP, skip it. The engine wants you at the retest, not the blow-off.

On the chart: a color-coded Trend Cloud and ribbon background. Green / cyan lean TREND with the move. Muted slate leans RANGE. Amber lean is TRANSITION — caution.

2.2 Pillar 2 — Liquidity Memory Map

Liquidity is resting stop orders. Buy-Side Liquidity (BSL) sits above prior highs. Sell-Side Liquidity (SSL) sits below prior lows. A sweep is price tagging those stops, then coming back.

Most tools delete a level after it is swept. Meridian does the opposite. It stores swept pools in a rolling 20-pool memory. Each pool is marked with intensity and a decay rate. As time passes, the magnet weakens. It does not vanish on the first touch.

  • Swept BSL / SSL become decaying magnets — price is often drawn back to them later.
  • High-intensity pools (fresh, large, session-linked) are gravitational targets for TP3.
  • TP3 is the third profit target — the furthest planned exit on the path.
Think of swept highs and lows as leftover fuel. The Memory Map remembers them so your third target has a real location, not a round number.

2.3 Pillars 3–4 — Lattice Confluence & Risk Geometry

Lattice Confluence is a count of agreeing events. Sweep + gap + cloud + session + magnet. More agreement = a higher grade. You will grade WATCH, PRIME, ELITE, and SINGULAR in Module 03.

Risk Geometry is the drawn path after the third gate clears: structural stop, confirmed entry, then TP1 / TP2 / TP3. You will manage PATH CONFIRM and PATH BREAK in Module 05.

Do not skip ahead to a lattice label if the regime is TRANSITION and the Memory Map is empty. Pillars stack. They do not replace each other.
Module 03 · Reading Live Signals & The 3-Gate Core

The 3-Gate Core & Event Lattice

Meridian never commits from a single trigger. Three gates clear in order. Then a density grade prints.

3.1 Three gates, in sequence

A gate is a must-pass check. Gate 01 must be true before Gate 02 matters. Gate 02 must be true before Gate 03 can print a tradeable zone.

Gate Name Requirement On-chart
01 Bias Regime classified: TREND, RANGE, or TRANSITION. Color-coded Trend Cloud and EMA ribbon.
02 Armed A live liquidity sweep, a CHoCH, or a Volume VWAP reclaim. ARMED label and timer on the recent swing high or low.
03 Zone Retest Price taps an unmitigated FVG or Order Block inside the time threshold. Event Lattice grade printed on the chart.

CHoCH means Change of Character — the first break that hints structure is flipping. Volume VWAP reclaim means price recaptures the volume-weighted fair-value line with participation, not a thin wick. An FVG (Fair Value Gap) is a 3-candle imbalance left by a fast move. An Order Block is the last opposing candle before that displacement. Unmitigated means the zone has not been fully filled yet.

If Gate 02 never arms, there is no trade. A pretty cloud is not enough. A lone FVG is not enough.

3.2 Event Lattice Density Grades

When Gate 03 clears, Meridian prints an Event Lattice grade. The grade is a density count — how many independent events agree on this bar.

WATCH
2

Sweep + FVG. Observe. Manual confirm only. Do not size up.

PRIME
3

Plus Trend Cloud alignment. Standard position size.

ELITE
4

Plus structure shift + VWAP + Session DNA. Full size.

SINGULAR
5+

Max confluence and a high-intensity magnet. Highest conviction.

WATCH · cyan PRIME · emerald ELITE · violet SINGULAR · amber

TRANSITION regimes need a higher grade before you arm. A WATCH in TRANSITION is a note, not a trade. PRIME is the default working grade in a clean TREND or RANGE. ELITE and SINGULAR are when session DNA and memory magnets stack.

Grade is not a guarantee. It is a confluence count. Size with the grade. Never invert it — do not take WATCH at full size.
Module 04 · Complementary Strategy Playbooks

Playbook A & Playbook B

One book for RANGE. One book for TREND. Same gates. Different geometry.

A Institutional VWAP Band Reversion · RANGE

When the regime is RANGE, fade stretched price back to fair value. VWAP is Volume Weighted Average Price — the session’s volume-weighted mean. σ (sigma) is one standard deviation from that mean. +2σ / +3σ is premium. −1σ / −2σ is discount.

  1. Regime RANGE. ADX below 20. Ribbon flat. Do not run this book in a strong TREND.
  2. Price at +2σ or +3σ VWAP. That is the premium zone — statistically expensive.
  3. Memory Map trigger. BSL is swept above a prior session high. Stops above the high are taken.
  4. Lattice PRIME or ELITE. WATCH is not enough size for this fade.
  5. Short the close. Stop above the sweep high. TP1 at Anchor VWAP. TP2 at −1σ. TP3 at the opposing SSL pool.
You are selling expensive, after the stops above the old high are gone, back toward the mean and then the opposite pool.

B ICT Silver Bullet Liquidity Expansion · TREND

When the regime is TREND, you do not fade. You join the expansion after London liquidity is taken. The Silver Bullet is a one-hour window: 08:00–09:00 New York. Hunt a displacement in that hour. Then wait for the retest.

  1. Time window. 08:00–09:00 AM EST only for the trigger. Management can run after 09:00.
  2. Regime TREND. EMA 9 above 21 above 50 (or the inverse for shorts). Trade with the stack.
  3. London high or low swept in the pre-market drive. That is the fuel.
  4. Displacement on the 1-minute or 5-minute leaves a fresh FVG and a CHoCH.
  5. Limit at 50% CE of the FVG. CE is Consequent Encroachment — the midpoint of the gap.
  6. Risk Geometry. Stop below the displacement swing low (longs). TP1 at the NY Open high. TP2 / TP3 at decaying Memory Map magnets.
Silver Bullet is a timed hunt, not an all-day license. If 09:00 prints and there is no displacement plus CHoCH, stand down.
Module 05 · Path Integrity & Dynamic Risk Geometry

Path Integrity & Live Trade Management

After Gate 03, Meridian draws the path. You manage the path. You do not invent a new trade mid-flight.

5.1 Dynamic Risk Geometry Path

Risk Geometry is the planned map from invalidation to target. It is structural, not a random round number. Once Gate 03 clears, the path prints on the chart.

R means risk multiple. 1.0R is one times the distance from entry to stop. TP2 at 2.0R is two times that distance. The magnet can stretch TP3 beyond a clean 3.0R when a high-intensity pool sits further out.

SL

Structural stop. Below the sweep or below the zone that would invalidate the idea. Not a feeling.

ENTRY

Candle-close confirmation. The bar must finish in your favor. Wicks during the bar do not count.

TP1

1.0R, or the VWAP mean, or the first sigma band. First scale. This is the integrity checkpoint.

TP2

2.0R. Mathematical second scale. Leave a runner if structure is still clean.

TP3

3.0R and / or the opposing liquidity magnet on the Memory Map. That is the gravitational target.

Draw the five levels before you click. If you cannot name SL and TP3 in one sentence, you are not ready to arm.

5.2 PATH CONFIRM and PATH BREAK

After you are in, Meridian tracks path integrity — did price respect the map, or did the map fail first?

PATH CONFIRM

Price reaches TP1 without touching the stop. The structure worked. Trail the stop to break-even. Protect the rest of the path.

PATH BREAK

A candle closes beyond the structural stop first. The path is invalid. Flat. No re-entry into that degraded setup.

  • PATH CONFIRM flags structural success. You have permission to manage, not to add size blindly.
  • PATH BREAK ends the idea. A close beyond the stop is the verdict. Do not “give it one more try” in the same zone.
  • A wick that tags the stop and comes back is noise. A close beyond the stop is a break. Honor the close.
Degraded setup = the original sweep, FVG, or regime read is spent. Hunting a second entry in the same mess is how accounts leak.

Five takeaways. Then practice.

  • Lock New York time. Standard candles. Alerts on bar close only.
  • Read the regime first. TREND goes with the cloud. RANGE fades VWAP. TRANSITION waits.
  • Swept liquidity is not gone. The Memory Map stores it as a decaying magnet — often your TP3.
  • Three gates in order: Bias, Armed, Zone. Then size by lattice grade: WATCH → PRIME → ELITE → SINGULAR.
  • PATH CONFIRM: TP1 first, trail to break-even. PATH BREAK: stop close first, stay flat. No re-entry into a spent setup.

Practice on replay. Bar-close only. Protect capital first. Precision, patience, edge.
