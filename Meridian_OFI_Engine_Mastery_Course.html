Module 01 · Foundation

Why Order Flow on Meridian

Order Flow Intelligence (OFI) is a volume read added on top of Meridian Engine v2. It sits on levels the engine already tracks.

1.1 The foundation is already built

Order flow means who is pushing, measured with volume. A footprint chart shows bid and ask at each price. This script does not have that feed. It uses a proxy, then drops the result onto the Meridian map you already know.

Five pieces of v2 make that possible. Each one already exists. OFI borrows them.

  • Event lattice. A short memory of event types near price. Each type counts once. The count becomes a grade: WATCH, PRIME, ELITE, or SINGULAR.
  • Liquidity Memory Map. A swept pool is stored as a magnet. The magnet decays each bar. A revisit with volume can strengthen it. Opposing magnets can become TP3.
  • Regime. TREND, RANGE, or TRANSITION. TREND needs ADX at or above the ADX TREND threshold (default 25) and a stacked EMA ribbon. RANGE needs ADX under the ADX RANGE threshold (default 20) and a mixed ribbon. Everything else is TRANSITION.
  • Path integrity. After an entry, the engine watches the map it drew. TP1 first is PATH CONFIRM. A close through the stop first is PATH BREAK.
  • Confirmed bars. A buy or sell label requires barstate.isconfirmed. The bar has closed. Mid-bar flicker cannot print the entry.

ATR is the average true range. It is a typical bar size. Several inputs are written as a multiple of ATR, so the same setting scales from a quiet chart to a wild one.

OFI does not build a second engine beside Meridian. It pushes two new event types into the lattice that is already there.

1.2 Why this engine, and what OFI is not allowed to do

OFI needs a place to land. The place is a list of event types, a price memory, and a grade that already decides entries. Two earlier engines were considered. They do not give OFI that place.

ICT Core

A simple 3-gate model, one FVG or order block, and a basic dashboard. There is no graded lattice to extend, and no magnet map to hang a level test on.

USME

Smart Money Score, SOTD tiers, and a multi-anchor VWAP. The score is flatter. Liquidity is simpler: cooldown-filtered PDH, PDL, and swing raids.

Meridian v2

Direction-matched magnets, a type-by-type lattice, regime gates, confirmed-bar entries, and mutual exclusion. New event types can join without a new signal path.

Gate 2 is the arm. The engine is armed only by a liquidity sweep, a VWAP reclaim, or a CHoCH. A long arm is a sweep of the lows, a bullish VWAP reclaim, or a bullish CHoCH. A short arm is a sweep of the highs, a bearish VWAP reclaim, or a bearish CHoCH.

CHoCH means change of character. In this script it is a break of structure that flips the structure trend. BOS means break of structure: a close through the last swing pivot. A CHoCH is a BOS. A BOS is not always a CHoCH.

Absorption does not arm Gate 2. Imbalance does not arm Gate 2. OFI can raise the grade, and it can change which side wins. It cannot arm the engine by itself.

There is also no separate “OFI Ready” badge in the script. The shipped stand-in is the alert thresholds in Module 05: absorption only when the grade is already PRIME or higher, imbalance only when the grade is already ELITE or higher.

Module 02 · Cumulative Volume Delta

Cumulative Volume Delta

CVD is a running total of bar delta. Bar delta is a proxy. It is built from the close, because many feeds have no bid and ask.

2.1 The up/down split, the slope, the session range

Bar delta is up volume minus down volume on one bar. The split looks at this close against the prior close.

  • Close above the prior close. The whole bar’s volume counts as up volume. Down volume is zero.
  • Close below the prior close. The whole bar’s volume counts as down volume. Up volume is zero.
  • Close unchanged. Volume is split in half. Up volume and down volume are each half the bar. Bar delta is zero.

CVD (cumulative volume delta) adds each bar delta onto a running total. Session CVD high and session CVD low are the highest and lowest values of that total since the last reset. They are tracked in the script. They are not a separate dashboard row.

The 3-bar slope is CVD now minus CVD three bars ago. Slope above zero means CVD rising. Slope below zero means CVD falling. Until three bars of history exist, both flags stay off.

Right after a reset, the three bars behind the slope can still belong to the old session. The slope can jump. Give the new session a few bars before you trust a CVD↑ or CVD↓ read.

2.2 CVD Reset — the input and the setup

Open the indicator settings. Find the group Event Lattice. The input is labeled CVD Reset. The default is Session. The choices are None, Session, and Daily.

None

CVD does not reset after the first bar. The total keeps running. Use this only when you want one long cumulative line.

Session · default

CVD resets when VWAP resets. It follows the preset’s VWAP anchor on purpose. Change the preset, and this reset follows.

Daily

CVD resets on each new New York day. It ignores the VWAP anchor. A weekly VWAP can sit under a daily CVD.

On a reset bar, CVD, the session high, and the session low are all set to that bar’s delta. They do not start at zero and then add. The first bar of the new run is the delta.

Session mode follows the preset anchor. Auto picks the preset from the chart timeframe.

PresetAuto whenVWAP anchorWhat Session reset uses

IntradayAbove 3 min, up to 15 minSessionThe same session window
SwingAbove 15 min, up to 4 hoursDailyThe new New York day

The session window itself depends on the symbol. Non-crypto uses 09:30–16:00 New York. Crypto uses a full 00:00–24:00 day, so the window never “opens” mid-week and the New York weekday change is what resets it. On Scalp or Intraday, a Session reset fires when that window opens, or when the New York weekday changes.

  1. Add the script. The indicator name is “Meridian Engine v2.1 — OFI”. It is Pine v6, and it overlays price.
  2. Open Event Lattice. Set CVD Reset. Leave it on Session unless you have a reason to break it away from VWAP.
  3. Leave the delta multiple. OFI strong-delta × avg defaults to 1.5. Minimum 0.5. Step 0.1. Module 03 uses this number.
  4. Leave the proximity. OFI level proximity (×ATR) defaults to 0.4. Minimum 0.1. Step 0.05. That is the magnet distance for absorption.
  5. Leave marks on. Show OFI marks defaults to on. One switch covers circles and diamonds.
  6. Read the closed bar. Entries wait for a confirmed bar. A mark can still change while the bar is forming, because delta uses the live close.
Module 03 · Types 8 and 9

Absorption and Imbalance

Type 8 and type 9 are direction-aware. A bullish event joins the long lattice only. A bearish event joins the short lattice only.

3.1 Absorption — type 8

Absorption means heavy volume in one direction that fails to continue. Sellers hit, and the candle still closes up. Or buyers hit, and the candle still closes down. The script stores both directions as type 8. The direction is a separate flag.

Strong delta uses the input OFI strong-delta × avg. Default 1.5. The script takes the 20-bar average of the absolute bar delta. Call that the average size. Strong up delta means this bar’s delta is greater than 1.5 times that average. Strong down delta means it is more negative than −1.5 times that average.

Abs↑ · bullish · direction +1

  • Strong down delta. Sellers are the effort.
  • Close above the open. The candle rejected that effort.
  • A long level is nearby. Any one of the three tests below.

Abs↓ · bearish · direction −1

  • Strong up delta. Buyers are the effort.
  • Close below the open.
  • A short level is nearby. The mirror of the three tests.

The level test is an OR. One true test is enough. Absorption does not also require the CVD slope. That requirement belongs to imbalance.

  1. Zone edge. A bullish FVG or order block is being tapped, and the low is at or below that zone’s bottom. On a bullish FVG the tap already keeps the low inside the gap, so the low has to sit on the lower edge. On a bullish order block the low has to reach the bottom of the block. The bearish test uses the high at or above the zone top. If no zone is tapped, this test is false. A missing zone is never treated as nearby.
  2. VWAP band. The close is within Band proximity (×ATR) of +1σ, −1σ, +2σ, or −2σ. That input lives in the group 3-Gate / Risk. Default 0.3. The ±1σ and ±2σ multipliers default to 1.0 and 2.0.
  3. Top magnet. A top magnet exists, and the close is within OFI level proximity (×ATR) of it. Default 0.4. This distance is the absorption magnet test. It is not the lattice’s own 1.5 × ATR proximity.
FVG means fair value gap, a three-bar price gap. In this lattice the FVG is type 7. Order block is optional and off by default (Show Order Blocks). Type 9 later in this module is an order-flow imbalance. It is not another name for the FVG.

3.2 Imbalance — type 9 — and the trap idea

Imbalance here means aggressive continuation. Strong delta in the trade’s direction, a CVD slope that agrees, and a structure or location event on the same bar. Both directions are type 9.

Imb↑ · direction +1

  • Strong up delta. Same multiple as absorption. Default 1.5 × the 20-bar average.
  • CVD rising. The 3-bar slope is above zero.
  • A bullish BOS, or a bullish VWAP reclaim, or a tap of a bullish FVG or order block.

Imb↓ · direction −1

  • Strong down delta.
  • CVD falling.
  • A bearish BOS, or a bearish VWAP reclaim, or a tap of a bearish zone.

A bullish CHoCH counts, because a CHoCH is a bullish BOS that flips the trend. A plain continuation BOS counts for the imbalance test too. A plain BOS does not arm Gate 2. Only the CHoCH form of that break arms.

A VWAP reclaim is a close back through VWAP, with volume above 1.2 times the 20-bar average volume. Bullish: this close is above VWAP and the prior close was at or below it. Bearish is the mirror.

The zone door for imbalance is the tap itself. Price is in the zone. That is wider than absorption’s edge test. Imbalance does not use OFI level proximity (×ATR). That input is the magnet distance on the absorption test. A magnet alone, with no BOS, no reclaim, and no zone tap, does not print type 9.

Exhaustion / trap, as this script actually handles it. There is no input that subtracts grade for “absorption against the regime.” The guard is the gates you already have. No-chase (±2σ in TREND) defaults to on. In TREND or TRANSITION, a long is blocked when the high reaches +2σ. A short is blocked when the low reaches −2σ. RANGE is allowed to touch those bands. TRANSITION also caps a soft grade at WATCH, which Module 04 covers. A green circle at +2σ in a strong trend is not a fade signal. With no-chase on, that long cannot print.
Module 04 · Lattice

Lattice Integration

Types 1 through 9 share one density function. The grade still enters through Gate 3. There is no fourth gate.

4.1 Nine types, counted once, on the same bar

The lattice keeps up to 30 recent events. Each event has a bar, a price, a direction, and a type code. Density asks a simple question: how many different types, on this side, are still in range?

CodeEventWhen it is pushed
1SweepSell-side sweep is long. Buy-side sweep is short.
2CHoCHA BOS that flips the structure trend.
3BOSA BOS that does not flip the trend. A CHoCH is not also stored as type 3.
4VWAP reclaimClose back through VWAP with expanded volume.
5Band touchA σ-band touch while price is in discount (long) or premium (short).
6Session tagSilver Bullet, NY defense, or Asia tag on that side.
7FVGA bullish or bearish fair value gap on this bar.
8AbsorptionThe type 8 test in Module 03. Direction follows the rejection.
9ImbalanceThe type 9 test in Module 03. Direction follows the delta.

An event counts only when three things are true. The direction matches the side you are scoring. The event is no older than the lattice window. The event price is within Lattice price proximity (×ATR) of the current close. Default 1.5.

The window input is Lattice lookback bars. Default 12. Minimum 3. Presets resize it. With the input left at 12, Scalp uses 8 bars, Intraday and Swing use 12, and Position uses 18. That is the time box for OFI events. There is no second OFI lookback input. A repeated absorption inside the window does not add a second point. Type 8 is already seen.

v2 counted each type once, in the spirit of a bitmask: one slot per type. Pine has no bitwise operators, so v2.1 stores nine true/false flags. The count is the same. Slots 8 and 9 are the new ones.

Density is calculated after this bar’s FVG and this bar’s OFI events are pushed. In v2, a same-bar FVG (type 7) missed the count until the next bar. That gap is closed. Types 8 and 9 are included on the bar they print.

4.2 Grade, the cap, mutual exclusion, regime

The number you see is the grade, not a raw tally that skipped the adjustments. The dashboard prints the name and that number together, like L ELITE(4).

  1. Count the slots that passed the window and the 1.5 × ATR price test.
  2. Session boost. Inside London (02:00–05:00 New York), the NY killzone (09:30–12:00), or the Silver Bullet (default 08:00–09:00), multiply by 1.25. Asia does not multiply.
  3. Round to the nearest integer. That integer is the grade, before the next two steps.
  4. Magnet bump. If a same-direction magnet has strength at least 1.0, price is within 1.2 × ATR of it, and the grade is already 3 or more, add 1. Cap at 5.
  5. TRANSITION cap. If the regime is TRANSITION, the grade is still under 4, and the pre-round density is under 3.5, cap the grade at 2. That is WATCH.

Do the OFI-only math once. Two types, and a session boost: 2 × 1.25 = 2.5, which rounds to 3 (PRIME). The magnet bump can then add 1, because the grade is already at least 3. That is 4, ELITE. SINGULAR is 5. Types 8 and 9 cannot get there by themselves, even with the session boost and the magnet bump. Without the session boost, two types round to 2 (WATCH), and the magnet bump does not apply, because the grade is under 3.

Gate 3 compares that grade with your minimum. The long passes when the long grade is at least the rank of Min lattice grade to enter. PRIME is rank 3. ELITE is 4. SINGULAR is 5. WATCH is 2. The same test runs on the short side.

Mutual exclusion runs after both raw signals exist. If both long and short qualify and the grades are equal, neither prints. If the grades differ, the higher grade prints. The winner still has to be a confirmed bar.

Regime does not multiply OFI by a hidden factor. RANGE, TREND, and TRANSITION change Gate 1, the no-chase rule, and the TRANSITION cap. The slot count itself uses the same formula. Module 06 is how you read absorption and imbalance inside those gates.
Module 05 · Chart and dashboard

Reading the Chart

The chart stays quiet. Two shapes, one dashboard row, four alerts. No footprint and no volume profile.

5.1 Circles, diamonds, and a hidden CVD line

Show OFI marks defaults to on. Turn it off and both shapes disappear. The shapes are tiny. They are cues, not a second panel.

Abs↑ · green circle · below the bar Abs↓ · red circle · above the bar Imb↑ · cyan diamond · below the bar Imb↓ · magenta diamond · above the bar
  • A bullish mark sits under the bar. A bearish mark sits over the bar.
  • The CVD series is plotted with display.none. It does not take over the price scale. Read the number on the dashboard.
  • Marks are not wrapped in barstate.isconfirmed. Delta uses the live close, so a mark can appear and vanish before the bar finishes. Treat it as final on the close.
  • The entry label is stricter. Buy and sell require a confirmed bar, the three gates, and the grade filter.
Minimal on purpose. The script does not tint whole zones, draw a footprint, or add a volume profile. If you need a louder chart, you are reading the wrong tool.

5.2 Dashboard row 12 and the four alerts

The dashboard is a 13-row table. Rows are numbered from 0. Row 12 is the last row. Its label is OFI. The cell shows one state word, then the live CVD value in volume format.

The word is chosen in this order. The first match wins.

Abs↑ / Abs↓

A bullish or bearish absorption is true on this bar. Absorption beats everything else in the cell.

Imb↑ / Imb↓

No absorption, and an imbalance is true. Imbalance beats the slope.

CVD↑ / CVD↓

No absorption and no imbalance. The 3-bar slope decides. If the slope is flat, the word is an em dash.

Read the word first. The tint checks bullish states before bearish states: Abs↑, Imb↑, or a rising CVD tints green. Otherwise Abs↓, Imb↓, or a falling CVD tints red. A bearish absorption that prints while CVD is still rising can show the word Abs↓ in a green tint. The word is the event. The tint followed the slope.

Four alertcondition names were added. They are separate from Enable alert() calls. That switch gates the other messages (entries, sweeps, regime, bias, path). It does not turn these four on or off. When you create the alert, choose once per bar close.

Alert nameFires whenMessage
OFI Absorption Long Bullish absorption and the long grade is at least 3 (PRIME) Meridian OFI: Bullish absorption at level
OFI Absorption Short Bearish absorption and the short grade is at least 3 (PRIME) Meridian OFI: Bearish absorption at level
OFI Imbalance Long Bullish imbalance and the long grade is at least 4 (ELITE) Meridian OFI: Strong bullish imbalance
OFI Imbalance Short Bearish imbalance and the short grade is at least 4 (ELITE) Meridian OFI: Strong bearish imbalance

A lone absorption on a weak lattice still draws the circle. It does not alert. The grade in the test already includes this bar’s event, because density runs after the push.

Module 06 · Playbooks and path

Playbooks and Path Integrity

Two ways to use the marks. Then the same path rules as v2, read with absorption in view.

6.1 RANGE fade, TREND continuation

These are reading rules. They use gates the script already has. A mark is not an entry. The entry still needs Gate 1, an arm, a zone, the filters, the grade, and a confirmed bar.

RANGE · absorption fade

  • Regime is RANGE. ADX is under 20 and the EMA ribbon is mixed.
  • Location is a magnet or a σ band. That is where type 8 is allowed to print. The lower band suits a bullish fade. The upper band suits a bearish fade.
  • Gate 1 for a RANGE long wants discount (close under VWAP minus half a standard deviation) or the lower extreme. The short wants premium or the upper extreme.
  • Gate 2 still needs a sweep, a VWAP reclaim, or a CHoCH. The circle does not arm.
  • Gate 3 still needs a tapped FVG or order block. A magnet with no zone does not enter.
  • No-chase does not block RANGE, so a ±2σ tag is allowed here.

TREND · imbalance continuation

  • Regime is TREND. ADX is at least 25 and the ribbon is stacked.
  • Gate 1 wants that stack, or price outside the cloud, on the trend side.
  • Type 9 agrees: strong delta with the trend, CVD slope with the trend, and a BOS, a reclaim, or a zone.
  • The arm is still a sweep, a reclaim, or a CHoCH. A CHoCH can arm and satisfy the BOS leg of imbalance on the same bar. A sweep arms, then imbalance has to show up with its own three tests.
  • No-chase blocks a long at +2σ and a short at −2σ. Continuation means you are not chasing the stretch.
Bullish absorption at +2σ during TREND is the trap the blueprint warns about. The circle can print if a long level is there. The long entry stays blocked while no-chase is on and the high is at +2σ. Do not override that block because the circle is green.

Whichever play you use, the grade still has to clear the minimum. Default is PRIME. If the other side’s grade is higher, mutual exclusion keeps this side quiet. If the grades tie, both stay quiet.

6.2 Absorption on an open path

OFI changes whether a path is created, because the grade includes types 8 and 9. Once the path exists, the tracker does not grow a new rule. The long path confirms when the high touches TP1. The long path breaks when a bar closes under the stop. The short path confirms when the low touches TP1, and breaks when a bar closes above the stop.

Holding the stop

A long is open. A bullish absorption prints, and the close stays above the stop. Sellers tried to push through the stop and failed. The dashboard path cell stays L:OPEN. That is the confidence the blueprint describes. PATH CONFIRM still waits for TP1. The circle does not move the stop and does not confirm the trade.

Failed absorption

The same defense appeared, and a later bar closes through the stop. The script prints PATH BREAK, clears that path, and can alert if Enable alert() calls is on. There is no second “failed absorption” alert. The break is the warning. The idea is over.

  • L:OPEN / S:OPEN means the path is active and TP1 has not printed.
  • L:CONFIRM / S:CONFIRM means TP1 was touched first.
  • L:BREAK / S:BREAK means the stop close happened first.
  • A wick through the stop is not a break. The script waits for the close.
Path integrity and the regime both read the same grade OFI just helped build. That is the whole wiring. No extra gate. No extra path engine.

Six takeaways. Then practice.

  • OFI is CVD, absorption (type 8), and imbalance (type 9) on the Meridian v2 lattice. It does not arm Gate 2.
  • CVD Reset defaults to Session, so it follows the VWAP anchor. Daily is the New York day. None never resets. The slope is three bars.
  • Absorption is strong opposing delta, a rejection candle, and a zone edge, a σ band, or the top magnet. Imbalance is strong same-side delta, a CVD slope that agrees, and a BOS, a reclaim, or a zone.
  • Density counts each of the nine types once, after the same-bar FVG and OFI pushes. Two OFI types cannot reach SINGULAR.
  • Circles and diamonds stay small. Row 12 shows Abs, Imb, or the CVD slope, plus the live CVD. Absorption alerts need PRIME. Imbalance alerts need ELITE.
  • RANGE can fade absorption at a magnet or a σ band. TREND can continue on imbalance after a sweep or a CHoCH. PATH CONFIRM is still TP1. PATH BREAK is still a close through the stop.

Replay the closed bar. Name the type, the direction, and the gate it is allowed to touch. If you cannot, leave the mark on the chart and keep your hands off the order.
